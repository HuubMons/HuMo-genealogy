The dutch genealogical search engine [http://www.stamboomzoeker.nl](http://www.stamboomzoeker.nl/) uses gendex to index family trees.

EXAMPLE:  
Root address: [http://www.website.nl/humo-gen](http://www.website.nl/humo-gen)  
Your URL: [http://www.website.nl/humo-gen/gezin.php?id=](http://www.website.nl/humo-gen/gezin.php?id=) (Don't enter anything after the xxxxx)  
Gendex file: [http://www.website.nl/humo-gen/gendex.php](http://www.website.nl/humo-gen/gendex.php)  
Privacy filter: not necessary, the gendex.php file filters persons after 1920. It's possible to adjust it.
